# End to end testing: desktop + mobile version

## Goal

Test the current app from the user point of view on:

- desktop layout
- mobile layout

## Focus

Check new features and recent UI behavior to find out:

- what should be improved
- what should be simplified
- what should be removed
- what causes friction in navigation

## Suggested checklist

- sidebar behavior on mobile
- tab switching behavior
- current page highlight
- folder expand/collapse logic
- tasks / Q&A / wiki switching
- code copy button behavior
- table of contents behavior
- relative links between pages

## Output

Create a short issue list with:

- problem
- device or screen type
- reproduction steps
- suggested fix
